Optional add-ons

Add names to the script file to switch on automatic tracking. Each add-on is about 0.25 KB.

bs.outbound.jsClicks on links to other websites, as the Outbound Link: Click event (with a url property)
bs.downloads.jsClicks on file links (pdf, zip, docx, …), as the File Download event
bs.downloads.outbound.jsBoth

Custom events, properties & revenue

Call bonestats(name, properties, revenue) anywhere after the script. Properties and revenue are optional:

<button onclick="bonestats('signup', {plan: 'pro'})">Sign up</button>
bonestats("purchase", {plan: "pro"}, 29.90)  // revenue in the goal's currency

Up to 10 properties per event with short text, number or true/false values. Don't put personal data (names, emails) in properties.

To record events before the script has loaded, add this one-liner above it:

<script>window.bonestats=window.bonestats||function(){(bonestats.q=bonestats.q||[]).push(arguments)}</script>

404 pages: add <script>bonestats("404", {path: location.pathname})</script> to your "not found" page and a 404 goal. Filter by that goal and the Properties card lists the broken URLs.

Privacy

  • No cookies, localStorage or fingerprinting on visitors' devices.
  • IP addresses are never stored. Visitors are counted with a hash whose salt is deleted every day.
  • Visitors who send Global Privacy Control or Do Not Track are not counted.
  • Data older than {{.Retention}} days is deleted automatically.
{{end}}
