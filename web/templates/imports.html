How imports work

  • Only days before bonestats recorded its first visit to this site are imported, so no day is counted twice. Importing the same days again is refused.
  • Umami data becomes regular visits: every card, filter and funnel works with it. Regions and Web Vitals aren't imported.
  • Plausible exports daily totals, not single visits. They show up in the overview, chart, pages, sources, countries, devices, events and goals, but only while no filter is on. Regions, cities and properties aren't imported. Visitors are unique per day, so over several days a returning visitor counts once per day.
